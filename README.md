# Thefoggy | Electronics Portfolio

Student portfolio of Mansouri Mohamed Amine, Electronic Engineering (Licence, 2023-2026) at USTHB, Algiers.

I design connected devices end to end: schematic and PCB, firmware, then a 3D-printed enclosure.


## Projects

### 01 - Smart WiFi Clock (final-year project)
ESP32-C3 SuperMini driving a 32x8 MAX7219 LED matrix.
- Time over NTP, weather from the OpenWeatherMap API, Pomodoro timer
- Browser-based settings and over-the-air (OTA) firmware updates
- Enclosure modelled in Fusion 360 over 4 iterations, printed in black PETG

### 02 - Custom Macroboard
Hot-swap macro pad built on the Raspberry Pi RP2040.
- 3x3 keys, 3 rotary encoders, 9 RGB LEDs, USB-C
- Custom PCB, QMK firmware remappable live with VIA
- Multi-part case designed in Fusion 360

### 03 - ESP32-S3 Dev Board
Development board designed in KiCad.
- ESP32-S3-MINI-1-N8, USB-C with ESD protection, 3.3 V LDO
- BME280 temperature/humidity sensor, RGB LED, SPI and programming headers
- Schematic, PCB layout and BOM included

## Tools
KiCad, EasyEDA, Autodesk Fusion 360, Arduino IDE, QMK/VIA, Wokwi, Adobe Premiere Pro
